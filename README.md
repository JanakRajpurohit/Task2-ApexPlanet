# 🍔 Crave — Food Delivery App UI Design

## 📌 Internship Details

* **Internship:** App Development Internship
* **Organization:** ApexPlanet Software Pvt. Ltd.
* **Task:** Task 2
* **Project Name:** Crave — Food Delivery App UI

## 📖 Project Overview

Crave is a food delivery app UI concept designed in Figma. The design focuses on creating an attractive, user-friendly interface that allows users to explore food items and view their prices and descriptions.

## 🎯 Objectives

* Practise mobile app UI design.
* Learn about layouts, colours, typography, and spacing.
* Create a consistent visual identity for a food delivery app.
* Explore screen navigation and prototyping in Figma.

## 📱 Screens Designed

### 1. Welcome Screen

* Crave branding and food-themed illustrations.
* Login and Sign Up buttons.
* Welcome message.

### 2. Login Screen

* Email or username input field.
* Password input field.
* Forgot Password option.
* Login button.
* Google sign-in UI concept.

### 3. Food Menu Screen

* Search bar.
* Grilled Club Sandwich listing.
* Classic French Fries listing.
* Food descriptions, ratings, and prices.

## 🎨 Design Features

* Food-inspired visual elements.
* Coral orange and teal buttons.
* Clean, mobile-oriented layout.
* Food images with product details.
* Consistent visual styling across screens.
